## 尚未验证与限制

- 当前 Xcode 环境具备编译工具、SDK 和可启动的模拟器运行时，但未找到可交互的 Simulator.app，无法完成 iPhone 界面输入、延迟自动保存及返回编辑页流程的交互验收。已通过的是模拟器构建／启动和数据核心保存检查，不能据此声称整个手机编辑流程通过。
- 真机安装、Apple ID 下 iCloud 文件上传下载、跨设备接续与同章冲突均待真机验证；本项目未实现可靠的并发冲突合并。
- 没有长文档性能基准、耗电／内存量测、自动化 UI 回归、无障碍专项测试和 App Store 发布验证。
- 图片导出数据路径已验证，人工文件选择器端到端仍可补验；手机预览、系统校对、全部快照恢复与外部文件夹授权恢复未逐项验收。
- 模式扫描无法识别所有秘密或证明完整开发历史权属；来源边界另见 SOURCE-NOTES。
